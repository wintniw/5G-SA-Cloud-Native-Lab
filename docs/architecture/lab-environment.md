# 5G Lab Environment

## Project
5G-SA-Cloud-Native-Lab

## Virtual Machine
- Hypervisor: Oracle VirtualBox
- Operating System: Ubuntu 26.04.1 LTS
- CPU: 4 vCPU
- RAM: Approximately 5.3 GiB
- Disk: 60 GB

## Installed Tools
- Docker
- Docker Compose
- containerd
- kubectl
- KinD
- Helm
- Git

## Planned Architecture
- 5G Core: Open5GS
- RAN and UE simulation: UERANSIM
- Container orchestration: Kubernetes
- Package management: Helm
- Monitoring: Prometheus and Grafana
- Version control: Git and GitHub

## Current Status
Initial virtual machine preparation completed.
GitHub repository created and cloned.
Open5GS deployment pending.
